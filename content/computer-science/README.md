# 计算机社区内容

本批内容只创建或复用当前账号可管理、名称为“计算机社区”的目标社区，不修改已有数学社区或其他计算机社区。

## 基础资料

foundations.md 包含五份独立导学文档，每份六章：操作系统、数据结构、计算机组成原理、计算机网络、计算机体系结构。正文是原创基础笔记，并提供官方标准、作者教材或大学公开课的延伸阅读链接，不复制整本教材。

## 案例研究

research-cases.md 包含六篇按研究问题命名的独立资料，不按课程打包成“案例集”：页面置换与缺页、范围查询索引、TCP 窗口、伪共享、事件驱动与背压、多核扩展。

采用摘要、研究问题、方法、结果或预期分析、局限、参考资料的结构。页面置换计数属于实际执行过的小型模拟；索引、窗口和并行上界属于明确假设下的解析模型；伪共享和服务压测部分是实验设计，不捏造实机时延、吞吐或加速数据。

verify-models.cjs 可用 Node.js 运行，核对文中的页面置换计数、树页容量、带宽时延积、窗口吞吐上界和并行模型。它不执行系统调优、网络压测或硬件性能测试。

## 录入与封面

GenerateComputerCovers.ps1 绘制十二张原创排版封面，位于 covers/。ImportComputerCommunity.ps1 通过 Java 业务接口录入内容与分类，设置社区、资料封面，建立课程和案例的互相跳转链接，并为目标社区关联“计算机”学科标签。SiteOrigin 指定页面链接域名，默认本机开发地址。

结果及文档 ID 记录在 science_community/community_service/target/computer-community-result.json；完成后拒绝直接重跑，避免重复导入。已有同名但正文不同的文档不会被覆盖。导入结果逐篇从服务器读回，并通过签名地址验证封面。无需新增数据表，基础与案例继续共用统一 Slate JSON 文档格式。
