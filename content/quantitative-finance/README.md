# 量化学习社区

基础资料包含五本常见量化书籍的书目信息、官方链接和原创六章学习导读，不包含原书全文、扫描件或仿制出版封面。学习章节为社区自定，非原书目录。案例按问题独立成篇，区分解析教学样例与尚未执行的实证方案，不提供虚构回测业绩。

学习顺序：Python 数据处理 → 量化交易研究流程 → 动量与均值回归 → 金融机器学习验证 → 组合稳健性。数学先修可结合数学社区的线性代数和概率论与数理统计。

`foundations.md` 与 `research-cases.md` 以 `---DOCUMENT---` 分隔文档。封面为原创排版，上传现有 S3；使用统一 Slate 文档结构及 base / case 分类。导入脚本使用运行时凭据，完成后保留无凭据清单，重复执行不会覆盖已完成导入。
